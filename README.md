# 몹 스크린샷 수집

1. 게임 화면을 띄운 상태에서 `capture_mobs.py`를 실행합니다.
2. F8을 눌러 몹이 보이는 화면을 캡처합니다.
3. 여러 각도와 거리에 대해 같은 몹을 많이 저장합니다.
4. `mob_screenshots` 폴더에 이미지가 생성됩니다.
5. 수집이 끝나면 F9를 눌러 종료합니다.

권장 사항:
- 같은 몹을 여러 각도에서 100~500장 정도 모으기
- 몹이 크게 보이는 화면 위주로 캡처
- 배경이 복잡하지 않은 장면을 중심으로 수집

수집 후에는 다음 단계로 YOLO 학습용 데이터셋을 구성하면 됩니다.

## 성능/메모리 최적화 체크리스트

새로 만드는 자동화 파일은 아래 항목을 항상 확인합니다.

- 무한 루프에서 화면을 너무 자주 캡처하지 않는지
- 전체 화면을 매번 처리하지 않고 필요한 영역만 보는지
- 일정 FPS를 넘지 않도록 막았는지
- 불필요한 객체를 계속 생성하지 않는지
- 키 리스너나 스레드가 중복으로 실행되지 않는지
- 메모리 사용을 높이는 큰 배열을 반복적으로 누적하지 않는지
- pyautogui, cv2, PIL 같은 작업을 상태가 활성화된 경우에만 실행하는지
- 파일이 길어질수록 함수로 분리해 반복 계산을 줄였는지
- 마우스 휠 스크롤처럼 짧은 입력이 반복되면 디바운스 처리를 했는지
- 화면 처리 전 필요한 크기로 먼저 축소했는지

이 규칙은 새 스크립트도 반드시 점검해야 합니다.
